API Mahasiswa dengan JWT

Sistem REST API sederhana dengan proteksi JWT untuk mengelola data mahasiswa.

Login Register
Akses Endpoint API

Endpoint dasar: http://api-native.test/api/mahasiswa

Method yang didukung:

  • GET - Ambil semua data atau berdasarkan ID
  • POST - Tambah data baru
  • PUT - Update data
  • DELETE - Hapus data
Catatan: Semua endpoint memerlukan token JWT valid dalam header Authorization.
Contoh Kode
// Contoh request dengan Fetch API
fetch('http://api-native.test/api/mahasiswa', {
    headers: {
        'Authorization': 'Bearer your_jwt_token'
    }
})
.then(response => response.json())
.then(data => console.log(data));

Login terlebih dahulu untuk mendapatkan token JWT valid.
