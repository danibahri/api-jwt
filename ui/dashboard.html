Dokumentasi Endpoint

Untuk uji coba API bisa menggunakan POSTMAN atau yang lain untuk pengujian
Setiap Endpoint API di Proteksi oleh JWT
Untuk mengakses API user di haruskan menginputkan token di header Authorization: Bearer {token} pada POSTMAN

  • GET /api/mahasiswa - Menampilkan daftar mahasiswa
  • GET /api/mahasiswa/{id} - Menampilkan daftar mahasiswa berdasarkan id
  • POST /api/mahasiswa - Menambahkan mahasiswa baru
  • PUT /api/mahasiswa/{id} - Mengedit data mahasiswa
  • DELETE /api/mahasiswa/{id} - Menghapus mahasiswa
